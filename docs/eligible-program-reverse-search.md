## 数据与匹配规则

数据只读取现有 `academic_schools` 与 `admission_offerings`；不新增表、不创建迁移，也不写入任何招生事实。

`eligible_major_categories` 在当前公开快照的 465 条记录中均为字符串。数据层统一支持以下输入，以便在线 Supabase 数据或后续快照格式变化时保持兼容：JavaScript 数组、Postgres 花括号数组文本、中文顿号、中文/英文逗号、中文/英文分号、竖线与换行。

- **专业名称明确匹配**：分词后的专业名称与用户输入（忽略首尾及内部空白）完全相等。
- **专业类别或相关范围可能匹配**：专业类、大类、相关专业等宽泛表述与输入存在至少两个字的共同前缀，或输入和范围文本互为包含；绝不作为确定资格。
- **报考范围不限**：官方原文明确出现“不限专业”“不限制专业”或“所有专科专业”。
- 结果按原始招生点逐条呈现，因此同校同专业的不同培养地点，以及不同文理/考试方案的公共课、专业课均不会被合并。

每条结果都展示院校、办学性质、本科专业、计划、培养地点/完整地址、报考范围原文、公共课、专业课、正式招生章程、正式考试大纲和院校专业地图入口，并重复提示：

> 该结果仅依据招生章程中的报考专业范围进行信息匹配，是否具备报考资格须以招生院校最终审核为准。
